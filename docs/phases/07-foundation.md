# Phase 07 — NestJS Foundation

## Objective

Build a clean, runnable production-oriented application skeleton.

## Stack

- NestJS
- TypeScript
- PostgreSQL
- Redis
- Configuration management
- Structured logging foundation
- Validation
- Exception handling
- Database integration
- Swagger

## End-to-End Work

Implement:

- Project structure
- Environment configuration
- Config validation
- Global validation pipe
- Standard exception handling
- Request/correlation ID foundation
- Logging
- Database connection
- Redis connection
- Health/readiness foundations
- Swagger
- Basic CI checks

## Exit Criteria

From a clean machine:

1. Dependencies install.
2. Infrastructure starts.
3. Migrations run.
4. Application starts.
5. Health endpoint works.
6. Swagger loads.
7. A test can connect to the database.
8. CI can lint, type-check, test, and build.

## Evidence

Runnable repository + setup documentation.
